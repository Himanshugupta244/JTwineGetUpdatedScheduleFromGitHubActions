About Interview Schedule Manager

An automated interview schedule management system that uses Selenium WebDriver for web scraping and Twilio REST API for voice call reminders. Built to streamline the interview process with real-time scheduling and automated notifications.

⚡ Key Features
📅

Automated Scheduling

Automatically scrapes interview schedules from multiple platforms and consolidates them into a single, easy-to-view dashboard updated in real time.

📞

Voice Call Reminders

Twilio-powered voice call reminders notify interviewers before upcoming sessions, ensuring no interview is ever missed.

📊

Real-time Dashboard

A live dashboard showing today's and tomorrow's interviews with status tracking, dropdown controls, and one-click join links.

☁

Cloud Deployment

Deployed on cloud infrastructure with GitHub Actions CI/CD pipeline for automatic schedule updates and page regeneration.
